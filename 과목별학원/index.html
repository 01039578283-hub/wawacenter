수업 중 이해한 내용과 혼자 공부한 결과를 왜 나누어 적나요?

설명을 들을 때와 자료 없이 다시 할 때 막히는 부분이 달라질 수 있기 때문입니다. 두 결과와 다음 점검 때 남은 내용을 구분하면 필요한 복습을 고르기 좋습니다.

무엇을 질문해야 할지 모를 때 어떻게 준비하나요?

읽어서 이해한 내용과 시도한 방법을 먼저 적고 그다음 막힌 부분을 표시해 보세요. 어느 표현이나 풀이 단계가 어려운지 좁혀 필요한 도움을 요청할 수 있습니다.

과목별 과제의 완료 기준은 어떻게 구체적으로 쓰나요?

공부할 범위와 함께 직접 설명하거나 작성할 결과를 적어 보세요. 핵심 메모·근거 답안·과정이 남은 풀이처럼 눈에 보이는 결과가 있으면 다음 점검에 활용하기 좋습니다.

동네 이름과 실제 방문할 지점은 어떻게 확인하나요?

여러 동네의 안내가 같은 센터로 연결될 수 있습니다. 관심 동네의 상세 페이지에서 지점명과 주소를 확인하고, 현재 운영 과목·가능 학년·방문 시간을 상담으로 확인하세요.

사진과 학습 안내가 모든 지점에 그대로 적용되나요?

사진은 공통 학습 공간 예시이며 실제 시설과 배치는 지점마다 다릅니다. 학습 점검 방법은 학생의 현재 상태를 살펴보기 위한 안내입니다. 실제 개설 과목·학년·시간표와 교습비, 기록·소통 방식은 해당 지점에서 확인하세요.

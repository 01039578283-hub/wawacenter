먼저 알아둘 답

수업 이름이나 과제량만 비교하지 말고 현재 자료를 어떻게 보고 다음 과제를 정하는지 질문하세요. 학년·과목·시간·교습비는 실제 지점의 안내 조건을 같은 기준으로 나란히 기록합니다.

먼저 확인실행 순서연습 예시기록 양식주의할 점다음 점검자주 묻는 질문참고 자료함께 볼 가이드

지금 상황을 먼저 확인하세요

수업 유형만 보고 선택하려 하나요?

소수 정원, 개별 지도 등의 표현만으로 학생에게 필요한 설명과 확인이 이루어지는지 알 수 없습니다.

학습 설명과 운영 조건이 섞였나요?

피드백 방식과 실제 제공 학년·과목·시간·비용을 따로 확인합니다.

이 순서로 직접 해 보세요

  1. 01

    학생의 필요 먼저 쓰기

    최근 자료에서 혼자 가능한 것과 도움받고 싶은 단계를 정합니다.

  2. 02

    진단과 과제 연결 질문

    처음 확인할 자료, 과제를 정하는 근거와 난도 조정 방식을 물어보세요.

  3. 03

    피드백과 재확인 질문

    틀린 이유를 어떻게 설명하고 다음 과제에서 학생이 혼자 한 결과를 어떻게 확인하는지 질문합니다.

  4. 04

    같은 운영 기준 비교

    학년·과목·횟수·시간·교습비·별도 비용과 확인 날짜를 나란히 기록하고 불명확한 항목은 다시 확인합니다.

자료에 적용하는 연습 예시

수업 비교 질문의 연습 예시

“관리해 주나요?” 대신 “숙제를 못 마친 이유를 시간 부족과 내용 어려움으로 나누어 보나요? 그 뒤 과제와 재확인은 어떻게 정하나요?”라고 질문할 수 있습니다.

조건이 비슷하다면 학생이 실제로 어려워하는 자료를 보여 주고 다음 과제와 확인 방식이 어떻게 연결되는지 다시 질문하세요. 비교 결과는 선택 이유와 남은 확인을 함께 기록합니다.

자주 묻는 질문

어떤 수업 유형이 가장 좋은가요?

유형 하나를 모든 학생에게 공통으로 추천하기 어렵습니다. 현재 필요한 설명, 독립 수행 확인과 실제 운영 조건을 함께 비교하세요.

상담 내용만으로 결정해도 되나요?

안내받은 내용을 실제 신청 수업의 조건과 연결해 확인하세요. 불명확한 비용·시간·학년·과목은 확인 필요로 남깁니다.

홈페이지에 있는 프로그램은 모두 운영하나요?

프로그램 소개와 지점의 실제 제공 조건은 다를 수 있습니다. 희망 학년·과목·일정의 수업 가능 여부를 해당 지점에 확인하세요.

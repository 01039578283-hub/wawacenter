먼저 알아둘 답

학교에서 받은 평가 안내를 기준으로 범위를 모은 뒤, 설명할 내용과 풀어 볼 문제를 나누세요. 진도 완료와 혼자 다시 할 수 있는 범위를 서로 다른 표시로 남기는 것이 출발점입니다.

먼저 확인실행 순서연습 예시기록 양식주의할 점다음 점검자주 묻는 질문참고 자료함께 볼 가이드

지금 상황을 먼저 확인하세요

시험 범위가 여러 자료에 흩어져 있나요?

교과서 단원, 배부 자료, 수행평가 안내의 제목과 날짜를 한 목록에 적습니다. 친구의 기억보다 학교의 최신 안내를 먼저 확인하세요.

공부한 단원도 다시 틀리나요?

해설을 본 뒤 맞힌 문제와 혼자 푼 문제를 구분합니다. 익숙해진 느낌만으로 완료 처리하면 복습할 부분이 가려질 수 있습니다.

이 순서로 직접 해 보세요

  1. 01

    학교 자료 목록 만들기

    과목마다 범위·자료·확인 날짜를 적고 모르는 범위는 교사에게 질문합니다. 학교별 배점이나 출제 방식은 추측하지 않습니다.

  2. 02

    교과서 내용부터 설명하기

    정의·핵심 문장·대표 예제를 책을 닫고 설명합니다. 설명이 끊긴 부분만 다시 확인하고 관련 기본 문제로 이어 갑니다.

  3. 03

    문제 뒤에 확인 행동 붙이기

    채점 후 틀린 이유와 다시 할 행동을 적으세요. “부호 확인 후 재풀이”처럼 다음 과제에 넣을 수 있어야 합니다.

  4. 04

    일정과 복습 자리를 함께 적기

    학교 과제와 수행평가 마감일을 먼저 놓고, 이미 공부한 범위를 다시 볼 자리를 남깁니다. 시험이 가까워질수록 반복 오류를 추려 확인하세요.

자료에 적용하는 연습 예시

한 단원의 학습 연결 예시

수학 방정식 단원이라면 “등식의 성질 설명 → 기본 문제 풀이 → 양변 연산을 놓친 문제 표시 → 다음 복습 때 대입으로 검토”처럼 이어 적습니다.

영어는 “학교 어휘 목록 → 본문 문장 구조 → 조건에 맞는 문장 쓰기”처럼 자료별 수행을 구분하세요. 이 예시는 학교 시험의 실제 범위나 배점을 정한 것이 아닙니다.

자주 묻는 질문
학교 자료와 문제집 중 무엇이 먼저인가요?
학교 평가 안내로 범위를 확인하고 교과서·배부 자료의 핵심을 정리하세요. 문제집은 그 범위에서 부족한 수행을 확인하는 용도로 고를 수 있습니다.
시간이 적으면 오답을 모두 다시 봐야 하나요?
반복 오류와 아직 설명하지 못하는 개념부터 추리세요. 제외한 항목도 표시해 시험 뒤 보완 목록으로 남기면 누락을 줄일 수 있습니다.
수행평가도 같은 계획표에 넣나요?
네. 시험 공부와 마감이 겹치는지 보이도록 넣되, 준비할 산출물과 제출 조건은 별도로 적어 주세요.
더 살펴볼 참고 자료
아래 자료의 학습 원리를 참고해 실행 순서와 연습 예시를 구성했습니다. 예시의 일정·문장·문제는 적용 연습용이며 학교 평가 기준이나 특정 학생의 실제 결과가 아닙니다.

학교 평가 안내, 범위·배점·제출 조건을 구분해 읽기

평가 안내를 받은 중·고등학생과 보호자

처음 게시 2026-10-03내용 업데이트 2026-10-03
먼저 알아둘 답

평가 계획과 과제 안내는 여러 조건이 담긴 문서입니다. “어느 단원인가”뿐 아니라 무엇을 설명하거나 제출해야 하는지 구분하세요. 문서에 없는 출제 비율이나 감점 규칙을 추정해 채우지 않고, 확인이 필요한 항목으로 남깁니다.

먼저 확인실행 순서연습 예시기록 양식주의할 점다음 점검학부모가 도울 때자주 묻는 질문참고 자료함께 볼 가이드

지금 상황을 먼저 확인하세요

단원 이름만 표시했나요?

설명·비교·계산·근거 제시처럼 요구하는 수행을 따로 적습니다. 같은 범위라도 필요한 답안 형태는 달라질 수 있습니다.

이전 안내를 그대로 쓰나요?

현재 받은 문서의 제목과 날짜, 변경 안내를 대조합니다. 작년 자료나 다른 반의 메모를 현재 조건으로 확정하지 않습니다.

이 순서로 직접 해 보세요

  1. 01

    문서의 적용 범위 확인하기

    과목·학년·학기와 안내 날짜를 확인합니다. 평가 계획과 개별 과제 안내가 다른 내용을 다루면 각각의 적용 범위를 적으세요.

  2. 02

    범위와 수행 요구 나누기

    교과 범위 옆에 요구한 답안 행동을 적습니다. 설명 문항이라면 정답 외에 어떤 근거나 비교 기준이 필요한지 원문에서 확인합니다.

  3. 03

    배점과 제출 조건 따로 읽기

    문서에 실제로 제시된 배점·형식·마감만 옮깁니다. 조건을 빠뜨렸을 때의 처리는 임의로 계산하지 말고 확인할 질문으로 둡니다.

  4. 04

    연습 과제와 확인 질문 만들기

    요구한 수행을 연습할 작은 과제를 정합니다. 서로 다른 안내가 충돌하거나 의미가 불분명하면 교사에게 원문을 보여주며 질문하세요.

자료에 적용하는 연습 예시

비교 서술형 안내를 연습으로 바꾸는 예시

연습용 안내가 “두 현상을 공통 기준으로 비교하고 근거를 쓰기”라면, 현상 이름 암기와 비교 문장 쓰기를 다른 과제로 잡습니다. 먼저 같은 기준을 정하고 자료에서 근거를 찾습니다.

배점이나 분량이 적혀 있지 않다면 예시 수치를 넣지 않습니다. “답안 분량은 별도 안내가 있는지”를 질문 칸에 남깁니다.

자주 묻는 질문
평가 계획만 보면 출제 문제를 알 수 있나요?
평가 범위와 요구를 확인하는 자료이지 특정 문항의 출제를 확정하는 자료는 아닙니다. 범위 안에서 설명과 적용을 연습하세요.
배점이 높은 부분만 공부하나요?
명시된 배점과 현재 수행, 과제 간 연결을 함께 보세요. 다른 항목에 필요한 기초를 빠뜨리면 계획을 다시 조정해야 합니다.
친구가 알려준 조건이 다르면요?
현재 안내 원문과 변경 공지를 먼저 대조하세요. 그래도 불분명하면 교사에게 문서의 어떤 부분이 다른지 구체적으로 질문합니다.

먼저 알아둘 답

시청률이나 앱의 완료 표시만으로 학습을 끝냈다고 보지 마세요. 자료를 닫은 뒤 설명하거나 해결한 결과를 함께 확인합니다. 사용하는 도구가 어떤 학습 목표와 질문·피드백 과정을 돕는지도 살펴보세요.

먼저 확인실행 순서연습 예시기록 양식주의할 점다음 점검자주 묻는 질문참고 자료함께 볼 가이드

지금 상황을 먼저 확인하세요

끝까지 봤지만 문제를 시작하지 못하나요?

시청 이후 스스로 해야 할 작은 과제를 정합니다. 설명을 다시 보는 것과 혼자 적용하는 것을 다른 결과로 기록하세요.

기능은 많은데 도움을 모르겠나요?

목표에 필요한 설명·연습·피드백·질문 경로를 확인합니다. 특정 기술이나 AI 표시가 있다는 이유만으로 학습 효과를 단정하지 않습니다.

이 순서로 직접 해 보세요

  1. 01

    자료를 고른 목표 적기

    현재 막힌 단원이나 수행과 해당 자료의 내용을 대조합니다. 자료 길이보다 필요한 설명이 무엇인지 먼저 봅니다.

  2. 02

    학습 뒤 할 과제를 미리 정하기

    짧게 설명하기, 첫 식 쓰기, 근거 문장 찾기처럼 화면을 닫은 뒤 할 일을 적습니다. 새 내용을 처음 배웠다면 필요한 도움을 구분하세요.

  3. 03

    시청과 실제 수행 따로 기록하기

    재생 시간·완료 표시와 혼자 한 과제 결과를 다른 칸에 적습니다. 자동 채점의 결과도 실제 답안과 대조합니다.

  4. 04

    피드백과 질문 경로 확인하기

    왜 틀렸는지 설명이 있는지, 이해되지 않는 부분을 어디에 질문할 수 있는지 봅니다. 연락·수업 지원 조건은 실제 서비스나 지점 안내를 확인하세요.

  5. 05

    다음 자료에서 다시 확인하기

    이전 정답을 기억하는 것과 다른 조건에서 적용한 것을 구분합니다. 반복되는 어려움은 자료 종류·난도·설명 필요성을 다시 검토합니다.

자료에 적용하는 연습 예시

수학 영상 뒤 독립 과제를 남기는 예시

방정식 설명을 본 뒤 영상을 닫고 다른 식의 첫 변형과 이유를 적습니다. 다시 재생해 확인했다면 도움받은 부분으로 표시합니다.

재생 완료와 도움 없이 설명한 범위를 따로 기록하세요. 이 예시는 특정 플랫폼·AI 프로그램이나 지점의 실제 수업 운영을 보증하는 설명이 아닙니다.

자주 묻는 질문
짧은 강의가 긴 강의보다 좋나요?
길이만으로 비교하지 않습니다. 현재 목표에 필요한 설명과 이후 연습·피드백이 있는지 실제 자료로 확인하세요.
앱의 점수를 보호자가 확인해야 하나요?
점수와 실제 답안·도움의 범위를 함께 살펴보세요. 학생과 무엇을 점검할지 먼저 정하고 서비스의 개인정보·공유 설정도 안내에 맞춰 확인합니다.
학원 수업 대신 사용할 수 있나요?
학생에게 필요한 설명·질문·독립 연습·관리 범위를 비교하세요. 이 글은 모든 학생에게 특정 수업 형태가 적합하다고 결정하는 자료가 아닙니다.

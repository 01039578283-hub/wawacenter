처음 게시 2026-10-01내용 업데이트 2026-10-01
먼저 알아둘 답

바로 완성 문장을 쓰기 전에 전달할 내용과 답안 조건을 나누어 적으세요. 초안을 쓴 뒤 조건 충족, 문장 구조와 철자를 다른 순서로 확인합니다.

먼저 확인실행 순서연습 예시기록 양식주의할 점다음 점검자주 묻는 질문참고 자료함께 볼 가이드

지금 상황을 먼저 확인하세요

뜻은 맞지만 조건을 빠뜨리나요?

필수 단어·시제·문장 수를 학교 안내에서 따로 표시합니다.

수정된 답을 외우기만 하나요?

왜 바뀌었는지 짧게 적고 다른 내용의 문장에서 적용해 보세요.

이 순서로 직접 해 보세요

  1. 01

    내용과 조건 나누기

    말할 뜻을 짧게 정리하고 필수 조건을 목록으로 적습니다.

  2. 02

    핵심 문장 먼저 쓰기

    주어·동사와 필요한 목적어·보어를 확인한 뒤 수식 표현을 연결합니다.

  3. 03

    조건 대조하기

    요구한 시제와 필수 표현이 실제 어디에 들어 있는지 표시합니다.

  4. 04

    수정 이유와 새 문장 남기기

    철자·형태·구조·내용 중 수정한 이유를 적고 비슷한 조건의 다른 문장을 씁니다.

자료에 적용하는 연습 예시

과거 시제의 연습 예시

“어제 도서관에 갔다”를 과거 시제로 쓰는 연습이라면 “I went to the library yesterday.”라고 쓸 수 있습니다.

“I go to the library yesterday.”를 고쳤다면 go를 went로 바꾼 이유를 적으세요. 실제 평가에서는 학교가 요구한 단어와 표현 조건도 확인해야 합니다.

빈 기록 양식 내려받기 (TXT)

  • 해설 문장을 외운 뒤 같은 예시만 쓰지 마세요.
  • 문법을 검토하면서 필수 내용 조건을 놓치지 마세요.
  • 자동 번역 결과를 이해하지 않은 채 자기 답안으로 사용하지 마세요.

다음 자료에서 다시 점검하세요

내용 구성이 어렵다면 짧은 뜻부터 말로 정리하세요. 구조와 형태가 어렵다면 실제 수정 전후 문장을 보여 주며 이유를 질문하고 직접 다시 써 봅니다.

자주 묻는 질문

문장을 길게 쓰면 좋은가요?

요구 조건과 전달할 내용을 정확히 충족하는지를 먼저 보세요. 불필요한 표현을 늘리다 조건이나 구조를 놓치지 않도록 합니다.

첨삭을 받으면 복습이 끝나나요?

수정 이유를 설명하고 다른 문장에 같은 조건을 적용해 보세요. 고쳐진 답을 읽는 것과 직접 쓰는 것을 구분합니다.

모르는 단어는 모두 찾아도 되나요?

연습 때 도움받은 표현을 표시하고 나중에 도움 없이 쓸 수 있는지 확인하세요. 학교 평가에서 허용되는 도움은 해당 안내를 따릅니다.

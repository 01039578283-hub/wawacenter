먼저 알아둘 답

새 교재를 정하기 전에 현재 책에서 혼자 한 범위와 다시 확인할 내용을 살펴보세요. 개념 설명·기본 적용·추가 연습처럼 책의 역할을 나누고 필요한 범위만 계획에 넣습니다. 교재안내의 자료는 선택 참고이며 지점의 실제 사용 교재는 별도 확인해야 합니다.

먼저 확인실행 순서연습 예시기록 양식주의할 점다음 점검자주 묻는 질문참고 자료함께 볼 가이드

지금 상황을 먼저 확인하세요

책은 여러 권인데 끝낸 범위를 모르나요?

책마다 주로 맡긴 역할을 적습니다. 같은 개념을 반복하는지, 서로 다른 수행을 확인하는지 살펴보세요.

정답 표시가 많아 진도를 바꾸려 하나요?

정답 여부 외에 혼자 설명한 범위와 도움받은 범위를 확인합니다. 해설을 보고 맞힌 것까지 모두 완료로 묶지 않습니다.

이 순서로 직접 해 보세요

  1. 01

    현재 교재의 역할 적기

    개념 설명·기본 적용·추가 연습 등 실제로 쓰는 목적을 정합니다. 책의 수준 표기를 학생의 능력 등급으로 바꾸지 않습니다.

  2. 02

    최근 수행 자료 확인하기

    한 단원에서 풀이·설명·오답·받은 도움을 살펴봅니다. 전체 책을 다시 푸는 계획 전에 남은 어려움을 고르세요.

  3. 03

    복습 범위와 완료 기준 정하기

    현재 책의 작은 범위로 과제를 정하고 다른 날 다시 확인할 항목을 적습니다. 반복 분량과 설명 필요성을 구분하세요.

  4. 04

    새 책이 필요한 역할 비교하기

    지금 자료에 설명이나 연습이 부족한지 확인합니다. 교재안내의 학년·영역·역할을 참고하되 학생의 최근 수행과 실제 수업 안내를 대조합니다.

  5. 05

    교체 후에도 이전 질문 남기기

    새 교재가 생겨도 해결하지 못한 개념·질문을 지우지 않습니다. 다음 자료에서 같은 수행을 확인하고 교재 선택을 조정하세요.

자료에 적용하는 연습 예시

기초 설명과 추가 연습을 나누는 예시

개념 설명용 책과 유형 연습용 책이 있다면 동일한 단원을 같은 분량으로 모두 계획하지 않습니다. 설명이 막힌 부분은 개념 자료로 질문하고 혼자 적용할 문제를 따로 고릅니다.

새 책을 고르는 경우에는 필요한 역할을 적어 교재안내와 비교하세요. 위 예시는 특정 교재의 효과나 해당 지점의 사용 사실을 주장하지 않습니다.

자주 묻는 질문
책을 끝내지 않고 바꿔도 되나요?
완독 여부만으로 정하지 않습니다. 현재 목표에 필요한 설명과 연습이 있는지, 실제로 감당할 난도와 분량인지 확인해 역할과 범위를 조정하세요.
이 사이트 교재가 학원 지정 교재인가요?
교재안내는 제공된 조사 자료를 바탕으로 선택을 돕는 콘텐츠입니다. 희망 지점의 실제 사용 교재와 교재비 포함 여부는 별도 확인합니다.
틀린 문제를 전부 반복해야 하나요?
첫 오류와 필요한 수행을 기준으로 복습 범위를 잡습니다. 같은 답을 기억하는 반복과 조건이 바뀐 적용을 구분해 재확인하세요.

식은 계산하지만 그래프의 의미를 설명하기 어려운 중·고등학생

처음 게시 2026-10-02내용 업데이트 2026-10-03
먼저 알아둘 답

식과 그래프를 서로 다른 암기 항목으로 두지 마세요. 같은 입력에 어떤 값이 나오는지 표로 확인하고, 그 점이 그래프 어디에 있는지 말로 설명합니다. 모양을 볼 때는 축의 단위와 적용 범위도 함께 봅니다.

먼저 확인실행 순서연습 예시기록 양식주의할 점다음 점검자주 묻는 질문참고 자료함께 볼 가이드

지금 상황을 먼저 확인하세요

그래프의 축이 무엇인지 빠뜨리나요?

가로축과 세로축의 양·단위·눈금을 먼저 적습니다. 눈금 간격이 다른 그래프를 모양만으로 비교하지 않습니다.

식의 숫자를 바꿔도 설명이 어려운가요?

입력과 출력 값을 몇 개 확인하고 무엇이 달라지는지 말합니다. 계수와 절편을 외운 문장으로만 설명하지 않습니다.

이 순서로 직접 해 보세요

  1. 01

    두 축과 식의 문자를 연결하기

    각 문자가 어떤 양을 뜻하는지, 문제에서 가능한 값의 범위가 정해졌는지 확인합니다.

  2. 02

    작은 값 표를 직접 만들기

    적용 가능한 입력 몇 개를 골라 값을 구합니다. 계산을 한 줄씩 남기고 점의 좌표와 구분하세요.

  3. 03

    표의 점을 그래프에서 찾기

    좌표가 축의 어떤 위치에 표시되는지 확인합니다. 축 눈금과 점의 위치가 맞지 않으면 표 계산과 표시를 따로 점검하세요.

  4. 04

    변화를 말로 설명하기

    입력이 바뀔 때 출력이 어떻게 달라지는지 표와 식을 대조합니다. 일부 점의 변화만으로 모든 함수의 성질을 단정하지 않습니다.

  5. 05

    다른 식과 적용 범위 비교하기

    항이나 계수를 한 가지 바꾸어 같은 입력의 값을 확인합니다. 실제 상황 문제에서는 음수·소수 입력이 허용되는지도 별도로 봅니다.

자료에 적용하는 연습 예시

y=2x+1을 연결하는 연습 예시

x가 0, 1, 2일 때 y는 1, 3, 5입니다. 표의 (1,3)이 그래프에서 가로축 1·세로축 3 위치라는 것을 설명하고, x가 1 증가할 때 y가 2 증가한 사실을 식과 대조합니다.

실제 개수를 다루는 예시에서는 x에 음수나 소수를 넣을 수 있는지 조건을 확인해야 합니다. 수학적 식의 입력 범위와 상황에서 허용하는 범위를 따로 적어 보세요.

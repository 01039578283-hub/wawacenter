## 개별화 기준

- subject-intro-answer의 실제 학습 상황을 우선한다. 이어지는 학년별 학습 상황과 본문 학습 절차도 근거로 쓴다.
- 센터 안내는 geo-answer-section의 학생 상황과 관리 방향에서 근거를 찾는다.
- 제목용 근거에는 후기, 시설 정보, 주소, 등록번호, 추천 링크, 숨김 요소를 사용하지 않는다.
- 한 문단에 학습 상황과 주소가 섞였으면 문장 단위로 구분해 학습 상황을 보존한다.
- 영어·수학 모두의 구체적인 어려움이 첫 답변에 있으면 두 과목을 함께 요약한다.
- 단일 과목 페이지에는 반대 과목의 접미사를 붙이지 않는다. 원고가 시간 배분·학습 습관에 집중하면 그 주제를 사용한다.
- 초등·중등 제목에 모의고사/수능을 추가하지 않는다.
- 지역 카테고리는 자신의 소개글에서 확인되는 주제로 요약한다.
- 같은 본문 주제에는 같은 접미사가 나올 수 있다. 지역명 해시나 무작위 표현으로 차이를 만들지 않는다.
- 센터 안내의 본문은 공통 주제가 많아 상세 원고보다 접미사의 종류가 적다. 본문 재작성은 이번 작업 범위가 아니다.

## 재사용

1. 원고 생성이나 다른 후처리가 필요하면 먼저 완료한다. 이번 제목 작업만을 위해 원고를 재생성하지 않는다.
2. python -X utf8 tools/test_title_suffixes.py
3. python -X utf8 tools/personalize_title_suffixes.py : 적용 계획만 만든다.
4. python -X utf8 tools/personalize_title_suffixes.py --write
5. python -X utf8 tools/personalize_title_suffixes.py --check
6. python -X utf8 tools/verify_title_release.py
7. 기존 GitHub main → Vercel 배포 후 python -X utf8 tools/verify_title_release.py --public

- title-suffix-audit.json이 실제 적용 내역과 근거·원본 해시의 기준이다. plan.json은 임시 계획일 뿐이다.
- 다음 원고 추가 작업에서는 고정된 페이지 수와 기준 커밋을 그 작업 범위에 맞게 갱신한다.
- title-suffix-release.json 및 title-suffix-public-verification.json은 배포 결과를 기록하는 로컬 파일이며 커밋하지 않는다.

# 초·중·고 영어·수학 안내 재생성

현재 주소는 `/지점안내/지역/실제지점/학년학원/수학·영어/`이며 188개 지점에 1,128개 과목 페이지가 있다. 동네명은 지점 페이지 안의 상담 참고 정보로 묶는다. 삭제한 동네 허브를 다시 만들지 않는다.

원본 원고·엑셀·CSV는 저장소나 공개 파일에 넣지 않는다. 허용된 12개 ZIP의 파일명, 인코딩, CRC, SHA-256과 371개 동네 매칭을 검토하고, 비공개 작업 폴더의 `manuscript-records.json` 및 `input-inspection.json`을 준비한다. 센터 자료가 달라졌다면 `branch-directory-data.json`의 사실을 먼저 대조한다.

1. 해당 작업의 검토 기준 커밋과 공개 목록을 `before-source.zip`, `before-manifest.json`으로 보관한다.
2. `python -X utf8 tools/prepare_subject_directory.py --audit 비공개작업폴더`로 두 원고의 학습 고민을 합치고 같은 의미의 항목을 정리한다.
3. `python -X utf8 tools/build_subject_directory.py --audit 비공개작업폴더`로 새 과목 페이지와 기존 디렉터리 부모를 생성한다. 지점·학년 생성기를 함께 실행했다면 이 과목 생성기를 마지막에 실행하여 과목 링크를 복원한다.
4. `tools/audit_subject_directory.py`로 전체 공개 링크, 메타 설명, FAQ, 교육비 표, 원본 보존과 URL TXT를 검사하고 `tools/test_subject_directory.mjs` 및 기존 테스트를 실행한다.
5. Vercel과 같은 빌드 명령을 실행하고 `tools/audit_grade_release.py`로 전체 산출물을 대조한다. 모든 수정 디렉터리 페이지의 모바일 검사와 주요 폭·상호작용 검사를 완료한다.

개설 학년은 과목마다 따로 판단한다. 미확인 학년, 운영 조건, 공통 참고 교육비, 학교명의 의미와 주소 확인 항목을 유지한다. 학습 점검 내용을 실제 지점의 개설 과정이나 성과로 바꾸지 않는다. 긴 상담 이미지와 모바일 원본을 온전히 노출한다.

페이지 설명은 실제 내용에 맞는 완결된 한국어 문장으로 80자 이내이며 메타·OG·Twitter·WebPage에 동일하게 반영한다. 신규 대표 주소만 사이트맵에 넣고 기존 1,113개 학년 이동 규칙을 유지한다. 배포 승인은 해당 작업의 사용자 요청을 따른다. READY 상태, 커밋, 실제 도메인 연결과 공개 응답이 일치하는지 검증한 뒤 완료로 기록한다.

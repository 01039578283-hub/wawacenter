폴더는 학교 과목과 단원 기준으로 정리하기

여러 앱에 파일을 흩어 놓기보다 주로 사용할 저장 위치를 정합니다.

파일명에 과목과 단원, 자료 종류를 넣어 보세요. 예를 들어 “영어_3단원_질문”처럼 이름을 붙이면 복습할 자료를 다시 찾기 쉽습니다.

필기에는 핵심 설명과 질문을 함께 남기기

화면을 예쁘게 꾸미는 데만 시간을 쓰지 말고 이해한 내용과 어려운 지점을 적습니다.

그림이나 식을 옮겼다면 왜 필요한지 짧게 설명해 보세요. 자료를 저장한 것과 학습을 끝낸 것을 구분해 완료 표시를 합니다.

강의 영상은 보기 전후 과제를 정하기

보기 전에 해결할 질문 한 개를 적고, 본 뒤 자료를 덮어 설명하거나 문제를 풀어 봅니다.

이어지는 영상을 자동으로 계속 보지 않도록 분량을 정하세요. 재생 시간이 아니라 이해를 확인한 내용을 기록합니다.

풀이 도구는 힌트와 검토에 제한해 활용하기

도구가 제시한 답은 교과서와 수업 내용으로 확인해야 합니다.

먼저 자신의 풀이와 막힌 부분을 남기고 필요한 힌트를 요청하세요. 특히 자동 생성 답변은 오류가 있을 수 있으므로 그대로 과제 답안에 옮기지 않습니다.

공유 자료에는 공개 범위를 확인하기

학교 자료나 교재를 다른 사람에게 공유해도 되는지 먼저 확인합니다.

개인 정보가 담긴 화면이나 학생의 기록은 공개하지 않도록 설정을 살펴보세요. 복습에 필요하지 않은 자료와 중복 파일은 정리해 찾기 쉽게 합니다.

디지털 자료도 다시 풀어 볼 목록 만들기

틀린 문제나 질문한 부분은 재확인할 날짜와 함께 표시합니다.

기기를 꺼도 기억해 설명할 수 있는지 확인하세요. 종이로 직접 계산하거나 문장을 쓰는 과제와 병행하면 실제 평가에서 필요한 작성 과정도 점검할 수 있습니다.

디지털 공부 자료 관리표

  • 저장 위치와 과목·단원 파일명을 정했습니다.
  • 자료마다 해결할 질문과 완료 기준을 적었습니다.
  • 도구의 답을 수업 자료로 확인했습니다.
  • 공개 범위와 다시 볼 문제 목록을 점검했습니다.
